# Referensi utilitas

Sumber yang digunakan dalam pembuatan tugas besar ini:

1. Matplotlib, [Quick start guide](https://matplotlib.org/stable/users/explain/quick_start.html).
   Membuat figure, sumbu, dan grafik objective.
2. Matplotlib, [Rectangle](https://matplotlib.org/stable/api/_as_gen/matplotlib.patches.Rectangle.html).
   Menggambar kendaraan sebagai persegi panjang pada dek kapal.
3. Matplotlib, [Figure.savefig](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.savefig.html).
   Menyimpan gambar state dan grafik sebagai PNG.
4. Python, [random](https://docs.python.org/3/library/random.html).
   RNG lokal dengan `random.Random(seed)` untuk inisialisasi yang dapat diulang.
5. Python, [time.perf_counter](https://docs.python.org/3/library/time.html#time.perf_counter).
   Mengukur durasi pencarian.
6. Python, [random.choices](https://docs.python.org/3/library/random.html#random.choices).
   Seleksi induk roulette wheel memakai bobot fitness, tanpa library GA tambahan.
7. Russell, S. dan Norvig, P. *Artificial Intelligence: A Modern Approach*, edisi 4,
   bagian 4.1.2, Figure 4.5, hlm. 115. Acuan alur simulated annealing.
   Jadwal pendinginan dan `evaluation_bias` ditentukan dalam implementasi proyek.
